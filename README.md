# NemichZVUK

Веб-интерфейс музыкальной библиотеки с управлением воспроизведением, очередью, поиском и подключёнными музыкальными источниками. Интерфейс оформлен в тёмном стиле с красным акцентом и адаптацией под компьютер и мобильные устройства.

## Требования

- Node.js 22 или новее
- pnpm 11.8 (версия указана в `package.json`)
- Доступный совместимый музыкальный сервер для функций воспроизведения и библиотеки

## Запуск для разработки

```bash
pnpm install
pnpm dev
```

Vite выведет локальный адрес приложения в терминал. По умолчанию используется порт `3000`.

## Проверка и сборка

```bash
pnpm test:run
pnpm build
```

Production-сборка создаётся в каталоге `music_assistant_frontend` — это имя каталога сохранено для совместимости с ожидающей его серверной частью.

## Основные каталоги

- `src/views/` — страницы приложения
- `src/components/` — повторно используемые UI-компоненты
- `src/layouts/default/PlayerOSD/` — нижний плеер, полоса перемотки и полноэкранный плеер
- `src/translations/` — языковые строки интерфейса
- `public/` — статические ресурсы и PWA-иконки
